## 通信特点

DDS1366 采用 RS-485 两线半双工、主从式通信，常见通信参数为 2400 bps、8 数据位、偶校验、1 停止位（8E1），通信参数及帧结构与 DL/T 645-2007 标准一致。

应用层实现的是标准子集：支持 `11H` 读数据（含 `0000FF00` 电能块与厂家 `F9` 族扩展项）、`13H`/`15H` 读/写通信地址（只认 `AAH×6` 形式）、`14H` 写数据（仅限厂家参数项，电能寄存器不可写）、`17H` 更改速率和 `1CH` 跳合闸（仅实现 `N1=1AH` 跳闸与 `N1=1CH` 直接合闸）；`12H` 读后续数据未实现，广播校时、冻结、清零等其余命令未验证，主站应一律按不支持处理。

在"非标准"方面，厂家提供了多种私有扩展：`F9` 族数据项（如 `F9010100` 电能+继电器状态组合读、`F9030100` 30 字节参数块）； `F9030100` 第 3 字节的"广播分组号"可实现分组批量拉/合闸管理；广播写 `99H×6 + 14H + F9AAAA01` 会无条件清零电能等。

总体上，本表以 DL/T 645-2007 为协议外壳，帧结构、编码、校验和多数数据标识符合标准，控制命令与保电、广播写等是"标准子集 + 厂家扩展"的组合。

完整的帧格式、数据标识清单、状态字语义与逐项符合性判定，见 [通信技术文档](DDS1366-communication-spec.md)。配套调试与模拟工具见 [工具简介](tools/README.md)。

## 连接方式

根据厂家说明页推断，电能表提供的 DL/T 645 光电接口与 485 通信口使用相同的权限层级与通信协议。可通过兼容 DL/T 645 的红外读写头或 RS485 转换模块连接到此电能表。

### 点对点连接

表体带 DL/T 645 光电接口，可用光电读头或红外掌机进行本地点对点通信，适合无 485 布线的现场抄读。红外信道一般默认 1200 bps 且不可更改。需要说明的是，本仓库工具未测试光电读头通信场景下的可用性，因此无法保证兼容性。

将调试设备经 RS485 转换器直接连接到电表的 485 端子（A 对 A、B 对 B），可实现物理点对点连接。此连接方式适合进行广播类帧的发送测试，以减小影响面。

### 总线并联

将调试设备经 RS485 转换器，直接连接到 485 总线上，或者并联到已接入 485 总线的电表 485 端子，可实现总线上设备的控制及主站监听。

由于半双工总线同一时刻只允许一个发送方，若总线上已有主站角色，调试设备应先被动监听，确认既有主站的轮询节奏，再在其事务之间的空闲窗口内注入请求。
